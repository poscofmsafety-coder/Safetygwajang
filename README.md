# safetygwajang

안전관리자를 준비하는 취업준비생과 현직 안전관리자가 함께 사용하는 학습·실무 웹사이트입니다.

## 이용자 흐름

- **취준생:** 자격증 → 영어 → 자기소개서 → 면접
- **재직자:** 현장 작업 대시보드 → 안전보건교육 → 위험성평가 → 위험성평가 실무 가이드 → 법령·지침 → MSDS → 밀폐공간·온열질환 → 사고·아차사고 기록

## 이번 UI 개편

- 서울남산체를 최우선으로 하는 한글 가독성 중심 폰트 스택 적용
- 한국어 문장이 단어 중간에서 어색하게 끊기지 않도록 `word-break: keep-all`, `text-wrap` 등 공통 가독성 규칙 적용
- **안전과장 캐릭터 제일이** 전신 투명 이미지와 안전모 `1` 머리 로고를 분리해, 전신이 필요한 화면에서는 팔다리가 잘리지 않도록 적용
- 메인·취준생·재직자·콘텐츠·면접·자기소개서·CBT 화면의 네이비/청록/안전황색 디자인 통일
- 특정 기업·공장·부서·업무의 사전 예시 데이터 제거
- 재직자 실무도구는 모두 **0건의 빈 데이터**에서 시작
- 재직자 화면마다 기록 **추가·수정·삭제·검색·JSON 내보내기/가져오기** 지원

## 현재 데이터 저장 방식

회원가입 기능을 붙이기 전 단계입니다.

- CBT 학습기록과 재직자 실무기록은 현재 브라우저 `localStorage`에 저장됩니다.
- 기기 변경이나 브라우저 데이터 삭제 시 사라질 수 있습니다.
- 재직자 기록은 각 화면의 **내보내기** 기능으로 JSON 백업이 가능합니다.
- 회원가입·아이디·비밀번호·개인별 서버 저장은 UI와 기능을 충분히 검증한 뒤 다음 단계에서 연결할 예정입니다.

## AdSense 관련

홈페이지에는 독자적인 설명형 콘텐츠와 사이트 소개·운영원칙·개인정보처리방침·이용약관을 유지했습니다. 재직자 개인 도구 화면은 `noindex,follow`로 검색 색인 대상에서 제외해 빈 사용자 데이터 화면이 검색용 콘텐츠로 평가되지 않도록 했습니다.

Google AdSense 승인은 보장되지 않으며, 기존 CBT 데이터에 제3자 자료가 포함돼 있다면 원출처와 재게시 권한은 운영자가 별도로 확인해야 합니다.

## KOSHA MSDS API
구성성분 CAS 법규 보조검토는 `KOSHA_API_KEY` Cloudflare Secret을 사용합니다. 공개 소스에 인증키를 넣지 마세요. 자세한 설정은 `API-SETUP.md`를 확인하세요.

## MSDS 보건관리 v7
- PDF 텍스트 레이아웃 추출 + 스캔 PDF/이미지 OCR 보조
- MSDS 2항의 신호어·GHS 코드·H 유해위험문구·P 예방조치문구 추출
- MSDS 3항의 구성성분·CAS No.·함유량 추출, CAS 체크디지트 검증 및 추출 신뢰도 표시
- MSDS 15항을 1차 근거로 작업환경측정·특수건강진단·특별관리물질 문구를 tri-state(대상/비대상 기재/확인 필요)로 보존
- 구성성분별 CAS를 KOSHA MSDS 공공데이터와 서버측 Secret으로 교차확인
- 혼합물에서는 한 성분의 비대상 결과가 다른 성분의 대상 결과를 덮어쓰지 않도록 성분별 결과를 집계
- 경고표지, 작업공정별 관리요령, 특별관리물질 고지 출력 화면 제공
- 자동 인식한 GHS 그림문자는 원본 2항과 사용자가 직접 대조·수정할 수 있으며, 명시적 코드가 없으면 보조 추정임을 표시
- 작업환경측정은 시행규칙 제186조·별표 21, 특수건강진단은 별표 22·23, 특별관리물질은 안전보건규칙 별표 12·제440조 최신본 최종 확인을 전제로 합니다.
