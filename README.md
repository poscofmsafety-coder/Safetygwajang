# safetygwajang

안전관리자 취업준비생과 재직자를 위한 정적 웹사이트입니다.

## 메인 구조
- 취준생: 자격증 → 영어 → 자기소개서 → 면접
- 재직자: 위험성평가 → MSDS → 밀폐공간 → 안전보건교육 → 법령·지침 → 사고·아차사고
- 기존 CBT/토익/자기소개서/면접 원본 기능과 데이터는 유지
- 재직자 기능은 제공된 EHS 앱을 일반 안전관리자용으로 재구성

## 배포
정적 파일 기준으로 저장소 루트의 `index.html`을 서비스하면 됩니다.
Cloudflare Workers/Pages에서 `safetygwajang.com`에 연결할 수 있습니다.

## 디자인
서울남산체를 최우선 로컬 폰트로 사용하며, 미설치 환경에서는 KT&G 상상체,
나눔바른고딕, Nanum Gothic, 함초롬돋움, 맑은고딕 순으로 대체합니다.
폰트 파일 자체는 저장소에 포함하지 않습니다.

## AdSense
승인 전 수동 광고 슬롯은 제거했고 AdSense 로더와 ads.txt는 유지했습니다.
콘텐츠·도구 페이지에서 최신 법령 및 공식 기준을 최종 판단 기준으로 안내합니다.
