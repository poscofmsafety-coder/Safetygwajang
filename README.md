# safetygwajang

안전관리자를 준비하는 취업준비생과 현직 안전관리자가 함께 사용하는 학습·실무 웹사이트입니다.

## 이용자 흐름

- **취준생:** 자격증 → 영어 → 자기소개서 → 면접
- **재직자:** 현장 작업 → 위험성평가 → MSDS → 밀폐공간 → 안전보건교육 → 법령·지침 → 사고·아차사고 기록

## 이번 UI 개편

- 서울남산체를 최우선으로 하는 한글 가독성 중심 폰트 스택 적용
- 한국어 문장이 단어 중간에서 어색하게 끊기지 않도록 `word-break: keep-all`, `text-wrap` 등 공통 가독성 규칙 적용
- 사용자가 제공한 **안전과장 캐릭터 제일이 원본 이미지를 그대로 보관**하고, 화면용 이미지는 원본 픽셀을 잘라 사용
- 메인·취준생·재직자·콘텐츠·면접·자기소개서·CBT 화면의 네이비/청록/안전황색 디자인 통일
- 포스코퓨처엠/FUTURE M/특정 부서·업무 예시 데이터 제거
- 재직자 실무도구는 모두 **0건의 빈 데이터**에서 시작
- 재직자 화면마다 기록 **추가·수정·삭제·검색·JSON 내보내기/가져오기** 지원

## 현재 데이터 저장 방식

회원가입 기능을 붙이기 전 단계입니다.

- CBT 학습기록과 재직자 실무기록은 현재 브라우저 `localStorage`에 저장됩니다.
- 기기 변경이나 브라우저 데이터 삭제 시 사라질 수 있습니다.
- 재직자 기록은 각 화면의 **내보내기** 기능으로 JSON 백업이 가능합니다.
- 회원가입·아이디·비밀번호·개인별 서버 저장은 UI와 기능을 충분히 검증한 뒤 다음 단계에서 연결할 예정입니다.

## AdSense 관련

홈페이지에는 독자적인 설명형 콘텐츠와 사이트 소개·운영원칙·개인정보처리방침·이용약관을 유지했습니다. 재직자 개인 도구 화면은 `noindex,follow`로 검색 색인 대상에서 제외해 빈 사용자 데이터 화면이 검색용 콘텐츠로 평가되지 않도록 했습니다.

Google AdSense 승인은 보장되지 않으며, 기존 CBT 데이터에 제3자 자료가 포함돼 있다면 원출처와 재게시 권한은 운영자가 별도로 확인해야 합니다.
